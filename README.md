## Projeto

#### Projeto web desenvolvido em Python utilizando o framework Django, com o objetivo de construir um site funcional para cadastro, exibição e gerenciamento de resenhas de livros.

A aplicação segue a arquitetura típica do Django, com models, views, URLs e templates HTML, aproveitando o ORM integrado para persistência de dados e renderização dinâmica de páginas.

O projeto conta com funcionalidades como autenticação de usuários, criação e edição de resenhas, listagem de livros e visualização detalhada de conteúdo, tudo por meio de uma interface web responsiva.

Principais tecnologias e conceitos aplicados:

– Python e Django Web Framework

– Django ORM para modelagem e persistência de dados

– Views e URL routing para lógica do servidor

– Templates HTML para renderização de páginas dinâmicas

– Formulários Django para cadastro e edição de informações

– Organização de arquivos estáticos e templates

– Boas práticas de desenvolvimento web full-stack


Principais aprendizados:

– Estruturação de aplicações web com Django

– Mapeamento objeto-relacional com Django ORM

– Manipulação de requisições HTTP e resposta dinâmica

– Construção de interfaces web usando templates

– Integração entre frontend (HTML/CSS) e backend Python
